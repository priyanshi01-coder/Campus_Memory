🧠Campus AI — connect a real model (optional)

By default, Campus AI answers using a local, offline lookup over your Campus Memory data — no key required, and it works everywhere. If you paste your own Anthropic API key below, Campus AI will call the real Claude API directly from your browser instead, still grounded in the same Campus Memory data.

⚠ Security note: this key is stored only in this browser's local storage and sent directly to Anthropic's API from your device — it is never sent anywhere else. Anyone with access to this browser/profile could read it from developer tools. Don't use a key with billing limits you're not comfortable with, and never do this on a shared computer. This exists for personal demo use only — a real product would keep the key on a server, never in the browser.
